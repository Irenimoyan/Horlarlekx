## 📌 About The Project

**HORLARLEKX Exterior Services** is a modern, high-performance web application designed to showcase high-end construction, exterior cladding, architectural facade engineering, corporate signage, and building finishing solutions. 

Built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**, the application features a responsive visual portfolio, interactive quote request system, detailed service showcases, and direct contact integration for clients across Nigeria and beyond.

---

## 🛠️ Core Services Featured

- **ACP Cladding Panels (ALUCOBOND)**  Premium exterior building aluminum composite panel cladding.
- **Corporate Signage & Pylon Signs**  3D illuminated channel letters, pylon towers, and outdoor business branding.
- **Architectural Glass & Aluminium**  Glass curtain walls, frameless glass railings, windows, and partition systems.
- **3D Architectural Designs**  Detailed 3D facade modeling, renders, and spatial design consultations.
- **Aluminium Roofing & Metal Works**  Custom roofing profiles, structural metal works, and safety railings.
- **Carpentry, Furniture & Suspended Ceilings**  Bespoke woodwork, interior fittings, POP, and drop ceiling systems.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js** (v18.0.0 or higher recommended)
- **npm** (v9.0.0 or higher) or **yarn** / **pnpm**

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Irenimoyan/Horlarlekx.git
   cd Horlarlekx
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173` (or the port specified in terminal).

4. **Build for Production**
   ```bash
   npm run build
   ```
   The compiled production assets will be generated in the `dist/` directory.

5. **Preview Production Build**
   ```bash
   npm run preview
   ```
